## 修复内容

### antgroup detail URL — 校招用错路径、社招路径不存在

**文件：** `cli/src/antgroup.ts:53-56`

**根因：** 之前 `DETAIL_URL` 两个分支都不对：

- Campus：`/campus-list?positionId=${id}` — `/campus-list` 是**列表页**，positionId query 被列表页忽略
- Social：`/off-campus-position-detail?positionId=${id}` — `/off-campus-position-detail` 这条路径在蚂蚁 SPA 上**根本没注册**，fallthrough 到根目录 shell

**研究方法：** agent 抓官方列表页的 React chunks，直接读到 `window.open(...)` 跳详情的代码：

- `p__CampusRecruitment__CRList__index.f7677fce.async.js`：
  ```js
  onNameClick: ... window.open("/campus-position?positionId=".concat(e,"&extType=").concat(u)+(i?"&tid=".concat(i):""))
  ```
- `p__SocialRecruitment__SRList__index.8e78803b.async.js`：
  ```js
  i.set("positionId",e); ... window.open("/off-campus-position?".concat(i.toString()))
  ```

也通过 SPA shell 大小对比确认：

- `/` → 42173B (fall-through shell — 没注册的路径全是这个)
- `/campus-list` → 43165B (列表页 — recognized 但是是列表)
- `/campus-position?positionId=…` → 42452B ✅ (recognized detail)
- `/off-campus-position?positionId=…` → 42452B ✅ (recognized detail)

**修复：** 改成 SPA 实际注册的两个路径：

```ts
const DETAIL_URL = (recruitType: "campus" | "social", id: string) =>
  recruitType === "campus"
    ? `https://talent.antgroup.com/campus-position?positionId=${encodeURIComponent(id)}`
    : `https://talent.antgroup.com/off-campus-position?positionId=${encodeURIComponent(id)}`;
```

实测 `https://talent.antgroup.com/campus-position?positionId=25062405364658` (post_id 来自实跑 `antgroup search`) 返回 43064B 的 SPA shell，与 root 的 42785B 明显不同 → SPA 进了正确的 detail chunk。
