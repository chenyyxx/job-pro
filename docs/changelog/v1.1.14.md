# v1.1.14 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

修了**莉莉丝（lilith）**的「scope 假装支持」问题 — 跟前一版 v1.1.13 修 Liepin 那几家是同一类型 bug。

## 🐛 修复的问题

之前 lilith 适配器声明支持 `--scope campus / social / intern / all` 四种，但实际上：
- 莉莉丝的飞书招聘板只有一个统一频道
- 所有岗位都打着 `recruit_label: "全职"` 标签
- 加 `--scope campus` 或 `--scope intern`，返回的还是同一批 65 个全职岗

现在直接报错：「lilith does not support --scope campus. Supported: social, all.」

## ⚠️ 注意事项

之前用 `--scope campus` 或 `--scope intern` 查莉莉丝的脚本会失败。改成 `--scope social` 或不带 `--scope`。
