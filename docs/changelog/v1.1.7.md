# v1.1.7 更新说明

## 🎉 这次更新做了什么？

URL 体检第三轮 — 修好了蚂蚁集团（antgroup）的详情链接。

## 🐛 修复的问题

### 蚂蚁集团（antgroup）详情链接打不开

- **之前的表现：**
  - 校招/实习链接打开是「校招职位列表页」，看不到具体职位
  - 社招链接是一个根本不存在的路径，跳到首页空白 shell
- **现在的表现：** 校招和社招都跳到正确的职位详情页

前一版的 URL 拼错了两次。修复后用蚂蚁招聘 SPA 自己实际注册的详情路径（`/campus-position` 和 `/off-campus-position`），跟官方列表页点开职位是同一条路。
