## 修复内容

### lilith supportedScopes 窄化为 ["social", "all"]

**文件：** `cli/src/lilith.ts:45-50`

**根因：** lilith 声明 `supportedScopes: ["social", "campus", "intern", "all"]`，但实测：

```
$ npx tsx src/index.ts lilith search --scope campus
total: 65, all recruit_label: "全职"

$ npx tsx src/index.ts lilith search --scope social
total: 65, same first post_id

$ npx tsx src/index.ts lilith search --scope intern
total: 65, same
```

三个 scope 返回完全相同的 65 个职位列表，全部 recruit_label="全职"。说明 lilithgames.jobs.feishu.cn 这个飞书板只有一个频道，feishu factory 的 `channelForScope` 没起作用。

这是和 v1.1.3 minimax 修复同一类问题 — adapter 在 `supportedScopes` 上承诺了 upstream 不支持的 scope。

**修复：** 窄化到 `["social", "all"]`。Matrix-fetch agent (batch D) 已经独立发现并标记了这个问题。

**验证：** `npx tsx src/index.ts lilith search --scope campus` → `Error: lilith does not support --scope campus. Supported: social, all.`
