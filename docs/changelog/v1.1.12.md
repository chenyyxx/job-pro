# v1.1.12 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

URL 体检覆盖范围从「每家公司测 1 个 scope」扩到「校招/社招/实习都测」，发现一个跨 7 家公司的系统性 bug — 全部用 Moka 招聘 SaaS 的厂家详情链接都拼成了**复数**形式（落到职位列表页），实际应该是**单数**形式。

## 🐛 修复的问题

一次性修好 7 家用 Moka 平台的公司详情链接：

- **月之暗面（moonshot）**
- **DeepSeek**
- **阶跃星辰（stepfun）**
- **智谱清言/Z智元（galaxyuniversal）**
- **吉利（geely）**
- **寒武纪（cambricon）** — 校招 + 社招两边都修
- **旷视（megvii）** — 校招 + 社招两边都修

之前点这些链接打开的是「全部职位列表」/「按城市分组」的概览页，需要用户自己再翻一遍。修好后直接落到具体职位详情。

## 🔬 顺带验证 PASS 的（v1.1.4-v1.1.11 修过的没回退）

通过浏览器复查这些 scope-distinct URL 都正常工作：bytedance 社招、baidu 社招+实习、iqiyi 校招+实习、xiaomi 社招+实习、antgroup 社招、meituan 社招、sf 社招、bilibili 社招、agibot 校招。
