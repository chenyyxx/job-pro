# v1.1.11 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

URL 体检第六轮 — 用真实浏览器（agent-browser）跑了一遍前几轮 curl 测不出来的 SPA 站点，修好了**携程**和**微博**。

## 🐛 修复的问题

### 携程（trip）详情链接打开是首页轮播

- **之前的表现：** 点开携程的职位链接，跳到的是携程招聘首页的公司介绍轮播
- **现在的表现：** 直接跳到对应的职位详情页

之前的 URL 用的是接口里的 UUID 字段（jobId），但携程招聘官网的 SPA 实际是按 MJ-代号（如 MJ033421）路由的，且要用 hash 路由 `#/experienced/job-detail/MJ034732`。

### 微博（weibo）详情链接显示「页面不存在」

- **之前的表现：** 点开微博的职位链接，Moka 招聘页直接报「您访问的页面不存在」
- **现在的表现：** 跳到对应的职位详情页

新浪 Moka 招聘租户用的是 hash 路由 + 单数 `#/job/<id>`，之前 URL 拼成了路径 `/job/<id>`（没有 `#`）。

## ⚠️ 已知问题

**理想汽车（liauto）** 详情链接仍然显示「请前往职位列表重新查找该职位」— 经浏览器验证，这不是我们的 URL 拼错，是 lixiang.com 自己的详情页对接口返回的所有 ID 都不识别（疑似 lixiang 官网详情页未公开 deploy，或后端有额外鉴权）。**这一项需要上游修复**，不在我们能修的范围内。
