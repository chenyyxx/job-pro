# v1.1.10 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

URL 体检最后一轮 — 修好了科大讯飞（iflytek）和 vivo 的详情链接（共用同一个北森 SaaS 后台，一次性两家都修）。

## 🐛 修复的问题

### 科大讯飞、vivo 详情链接打不开

- **之前的表现：** 点开链接跳到的是公司的招聘列表页，看不到具体职位
- **现在的表现：** 跳到对应的职位详情页

两家公司都用北森（Beisen）招聘 SaaS（`*.zhiye.com`），之前 URL 用的是 `/jobs?jobAdId=` 这个其实是**列表页路由**。北森的 SPA 把详情页注册成 `/social/detail`、`/campus/detail`、`/intern/detail` 三条单独路由，按职位的招聘类型（校招/社招/实习）走对应路径。
