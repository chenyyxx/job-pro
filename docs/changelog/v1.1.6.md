# v1.1.6 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

URL 体检第二轮 — 修好了美团的详情链接。

## 🐛 修复的问题

### 美团（meituan）详情链接打不开

- **之前的表现：** 点开美团的职位链接，立刻被服务器跳转到「美团社招」列表首页，看不到具体职位
- **现在的表现：** 直接跳到对应的职位详情页

之前的 `/job-list/{id}` 路径在美团服务器上根本不是详情页路由 — server 直接 302 重定向到 `/web/social` 列表页。修复后用美团 SPA 实际注册的详情路径，参数也跟着分享链接的格式给齐了（社招/校招会自动区分）。
