# v1.1.13 开发日志

> 发布日期：2026-05-24

## 修复内容

### 4 个 Liepin-backed 适配器漏 export `supportedScopes`

**文件：** `cli/src/{cainiao,webank,cicc,hikvision}.ts`

**根因：** Liepin factory (`liepin.ts:461`) 在返回的 adapter object 上声明了 `supportedScopes: ["social", "all"]`，但 4 个调用方都只 `export const x = adapter.x` 选择性 re-export 了方法，没把 `supportedScopes` 也透传出来。

dispatcher 在 `index.ts:602-604` 的检测逻辑：

```ts
const supported =
  (adapter.supportedScopes as readonly string[] | undefined) ??
  (POSITION_SCOPES as readonly string[]);  // ← fallback to ALL 4 scopes
```

当 adapter 不声明 supportedScopes，fallback 是 "accept all 4 scopes"。所以 `cainiao --scope campus` 走通了，但 Liepin factory 内部对 scope 参数完全无视 — 返回的仍是同一批社招数据。silent fallback = 错误的伪 PASS。

**修复：** 每个适配器加一行 `export const supportedScopes = adapter.supportedScopes;`。

**验证：**

```bash
$ npx tsx src/index.ts cicc search --scope campus
Error: cicc does not support --scope campus. Supported: social, all.

$ npx tsx src/index.ts cicc search --scope social
{"ok": true, "source": "api-c.liepin.com", ...}
```

(同样对 cainiao / webank / hikvision 生效)

## 影响

dispatcher 现在正确拒绝 4 家 Liepin 适配器的 campus / intern scope。如果有调用方之前依赖 silent fallback，需要改成 `--scope social` 或省略 `--scope`。

修复总数：17 个 adapter（v1.1.12 的 moka factory 一次性算 7 + weibo + 之前 8 个独立修 + 这一版 4 个 supportedScopes 漏 export）。
