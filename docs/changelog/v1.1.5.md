# v1.1.5 更新说明

> 发布日期：2026-05-24

## 🎉 这次更新做了什么？

继 v1.1.4 修了小红书之后，又做了一轮全量 URL 体检，发现并修好了莉莉丝的同类问题。

## 🐛 修复的问题

### 莉莉丝（lilith）详情链接打不开

- **之前的表现：** 点开莉莉丝的职位链接，跳出来的是个干巴巴的「加入莉莉丝」页面，看不到职位详情
- **现在的表现：** 直接跳到对应的职位详情页，能看到完整的职位描述

跟上一版小红书那个 bug 是同一类问题 — 详情页路径用错了，飞书的标准是 `/index/position/{id}/detail`，之前用的 `/career/{id}/detail` 会落到首页 SPA shell。

## ⚠️ 注意事项

无 breaking change。直接更新就好。
